# Velorah® Hero

Single-page cinematic hero built with:

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui-style Button component
- Google Fonts: Instrument Serif + Inter

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The hero uses the supplied CloudFront MP4 as a fullscreen looping background video.
